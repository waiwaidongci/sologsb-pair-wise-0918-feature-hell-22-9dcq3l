# hxyfront-62012 纺织染整小样管理

源提示词编号：7

我需要一个纺织染整实验室的小样管理前端系统，可以记录面料成分、克重、染料配方、浴比、温度曲线、保温时间、后整理方式、色差值和评审结果。页面需要有小样批次列表、配方比例展示、Lab色差对比、工艺曲线摘要和按客户订单筛选。

## 功能

- **批次管理**：新增 / 编辑 / 状态流转（待评审、评审通过、待复染、客户确认中），保留 LAB-620A、LAB-621C、LAB-624B 三条初始记录。
- **联动校验（不满足不能保存，原因标注在字段旁）**：
  - 面料成分百分比合计必须等于 100%；
  - 染料配方占比合计必须等于 100%；
  - 温度曲线时间严格递增，任一升温段不得超过 3℃/min；
  - 保温时间不得超过曲线在最高温的平台时长（保温时间与曲线不符即拦截）；
  - 克重 / 浴比 / 成分 / 最高温另有软提示（琥珀色，不阻断保存）。
- **Lab 色差**：按 CIE76 公式实时计算 ΔE 并映射变色灰卡判级（5级 ~ 2-3级）；ΔE > 0.8 时「通过评审」锁定，只能存为待复染。
- **筛选联动**：按客户/订单关键字与成分（棉、涤纶、锦纶、混纺）筛选后，配方比例堆叠图、Lab 色差判级卡片、工艺摘要（含温度曲线小图）同步更新。
- 支持导出筛选结果 CSV。
